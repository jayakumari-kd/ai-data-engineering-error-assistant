# Data Engineering Error Library

A personal troubleshooting knowledge base for Data Engineering errors, investigations, reproductions, fixes, and lessons learned.

## Purpose

This repository captures practical Data Engineering troubleshooting knowledge based on:

- Real project incidents
- Controlled local reproductions
- Actual error messages and logs
- Root-cause investigations
- Configuration experiments
- Fixes and lessons learned

The goal is to make this knowledge reusable for future troubleshooting and searchable by AI assistants such as Claude and GitHub Copilot.
